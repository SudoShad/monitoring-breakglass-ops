# Examples

Sample payloads for interview demos and `parse-alert.ps1` / break-glass walkthroughs.

| File | Use |
|------|-----|
| `sample-alert-p1.json` | Flat P1 alert |
| `sample-alert-p2.json` | Flat P2 alert |
| `sample-alert-p3.json` | Flat P3 alert |
| `sample-prometheus-webhook.json` | Prometheus Alertmanager-style webhook envelope |
| `sample-breakglass-approved.json` | Approved break-glass ticket shape |

All names (`contoso.example`, `jdoe`, etc.) are fictional. Do not replace these with real tenant data in commits.
